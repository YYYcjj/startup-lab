# 个人财务管理

## 方向概述

中国人均使用 3-5 个支付/金融 App（微信、支付宝、银行 App、信用卡、证券），但缺乏一个统一的、AI 驱动的个人财务视图。记账 App 很多，但**需要手动输入**是最大障碍。

## 核心痛点

| 痛点 | 描述 | 严重度 |
|------|------|--------|
| 多账户碎片 | 钱分散在多个平台，总资产不透明 | 🔴 P0 |
| 手动记账反人性 | 90% 的记账用户 30 天内放弃 | 🔴 P0 |
| 不知道钱去哪了 | 月底看账单才惊讶 | 🟠 P1 |
| 理财决策无依据 | 不知道该怎么配置资产 | 🟠 P1 |
| 订阅黑洞 | 忘记取消的自动续费 | 🟡 P2 |

## AI + 自动化机会

| 方向 | AI 能力 | 自动化体现 | 专利潜力 |
|------|---------|-----------|----------|
| **自动记账** | OCR + NLP 识别账单 + 自动分类 | 截图/通知栏自动捕获 | ⭐⭐⭐⭐⭐ |
| **资产聚合** | 多源数据融合 + 去重 | 自动同步各平台余额 | ⭐⭐⭐ |
| **智能预算** | 消费行为预测 | 动态调整预算 + 预警 | ⭐⭐⭐⭐ |
| **订阅管理** | 定期扣款识别 | 自动提醒即将续费的订阅 | ⭐⭐ |
| **税务优化** | 抵扣项自动识别 | 个税汇算自动整理 | ⭐⭐⭐⭐ |

## 典型用户场景

### 场景：月底财务快照
```
用户：什么都不做
系统：自动抓取微信/支付宝/银行卡账单
AI：分类、去重、标记异常
输出：本月总支出 ¥8,420，餐饮超预算 15%，3 个续费订阅可取消
```

## 专利机会

最有价值的专利方向：**基于多源异构数据融合的个人财务自动分类方法**

- 从银行短信、App 通知、截图等多渠道获取数据
- NLP 统一语义理解
- 用户行为学习持续优化分类准确率
- 形成完整财务画像

## 竞品格局

| 竞品 | 定位 | 优势 | 劣势 |
|------|------|------|------|
| 随手记 | 手动记账 | 老牌、功能全 | 需要手动输入 |
| 钱迹 | 极简记账 | 体验好 | 功能有限 |
| 微信记账本 | 自动抓取 | 零输入 | 仅限微信 |
| 支付宝账单 | 平台内 | 自动 | 仅限支付宝 |
| Mint（美国） | 自动聚合 | 连接银行 | 中国不可用 |

## 切入建议

1. 先做「自动记账」— 最大痛点，技术可行（OCR+NLP）
2. 再做「订阅管理」— 简单但高价值（直接帮用户省钱）
3. 最后做「资产聚合」— 需要开放银行 API

> 关键壁垒：**分类准确率**。如果 AI 自动分类准确率 > 95%，用户留存会非常高。
