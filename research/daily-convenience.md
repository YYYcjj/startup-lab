# 日常便利工具

## 方向概述

日常生活中的「微痛点」— 单个看起来不大，但因为高频累积起来很消耗精力。这类产品通常小而美，适合个人开发者或小团队。

## 核心痛点

| 痛点 | 描述 | 严重度 |
|------|------|--------|
| 信息整理 | 收藏的文章/链接/截图永远不整理 | 🟠 P1 |
| 行程规划 | 多人聚会协调时间、旅行计划 | 🟡 P2 |
| 家庭事务 | 家务分工、账单分摊、购物清单 | 🟠 P1 |
| 证件管理 | 各种证件到期/续期记不住 | 🟠 P1 |
| 送礼提醒 | 生日/纪念日/节日 + 选礼物 | 🟡 P2 |

## AI + 自动化机会

| 方向 | AI 能力 | 自动化体现 | 专利潜力 |
|------|---------|-----------|----------|
| **AI 知识管家** | 自动分类 + 摘要 + 语义检索 | 收藏即整理，需要即找到 | ⭐⭐⭐⭐ |
| **智能行程规划** | 多人时间协调 + 偏好匹配 | 自动生成最优方案 | ⭐⭐⭐ |
| **家庭协作助手** | 语音录入 + 自动分配 | 家务轮值 + 清单同步 | ⭐⭐ |
| **证件到期提醒** | OCR 识别 + 规则引擎 | 拍照自动提取到期日 + 提醒 | ⭐⭐⭐ |
| **智能送礼** | 用户画像 + 电商匹配 | 自动提醒 + 推荐礼物 | ⭐⭐⭐ |

## 典型案例：AI 知识管家

```
问题：用户每天在微信/知乎/微博/浏览器收藏 10+ 篇文章
结果：收藏 = 永远不会再看

AI 方案：
1. 自动抓取所有平台的收藏
2. AI 自动分类 + 打标签 + 生成摘要
3. 用户需要时，一句话搜索："上次看到那个关于 React 性能优化的文章"
4. AI 自动整理成知识库，定期推送回顾
```

## 竞品格局

| 竞品 | 定位 | 优势 | 劣势 |
|------|------|------|------|
| Cubox | 稍后阅读 | 体验好 | 需手动操作 |
| Pocket | 稍后阅读 | 老牌 | 国际化，中文弱 |
| Raindrop | 书签管理 | 功能全 | AI 能力弱 |
| Readwise | 阅读回顾 | 回顾机制好 | 贵、英文为主 |

## 切入建议

1. **AI 知识管家** — 从「收藏自动整理」切入，扩展到知识管理
2. **证件管理** — 简单但刚需，适合作为第一个产品练手
3. **智能送礼** — 商业化明确，电商佣金模式

> 这类产品适合**先验证再开发**。用人工 MVP 验证：自己帮 10 个朋友整理收藏，看他们愿不愿意付费。

**ICE 预估**：I=6 C=8 E=8 → **7.3** ⭐（容易上手，适合第一个项目）
