# 产品化与市场策略

## 从 MVP 到产品

MVP 验证通过后，进入产品化阶段。这阶段的核心问题是：

> 怎么让更多人来用，而且愿意持续用？

## 产品化三阶段

### 阶段 1：PMF（Product-Market Fit）

**目标**：找到产品和市场的匹配点

| 信号 | 表现 |
|------|------|
| ✅ 强 PMF | 用户主动推荐、留存率高、客服压力大 |
| ⚠️ 弱 PMF | 用户用但不兴奋、留存还可以但不增长 |
| ❌ 无 PMF | 用户来了就走、需要不停解释产品价值 |

> Sean Ellis 测试：问用户"如果不能再使用这个产品，你有多失望？" → 超过 40% 选"非常失望" = PMF

### 阶段 2：规模化增长

**目标**：在 PMF 确认后快速扩张

增长策略：
- **内容营销**：写教程/案例/对比文章，解决用户搜索的问题
- **产品驱动增长（PLG）**：免费版引流，产品自身的分享/邀请机制
- **社区运营**：建立微信群/Discord，让用户互帮互助
- **SEO/ASO**：搜索词优化，让用户能找到你

### 阶段 3：商业化

**目标**：建立可持续的商业模式

| 模式 | 适合 | 优点 | 缺点 |
|------|------|------|------|
| **订阅制** | 持续提供价值的工具 | 收入可预测 | 需要持续迭代 |
| **按量付费** | AI API 类产品 | 用户按需付费 | 收入不稳定 |
| **Freemium** | 大众市场 | 获客容易 | 转化率是关键 |
| **一次性购买** | 功能明确的小工具 | 用户决策快 | 无持续收入 |
| **B2B SaaS** | 企业效率工具 | 客单价高 | 销售周期长 |

## AI 产品的定价策略

AI 产品的特殊性：有持续的计算成本（API 调用）。

| 层级 | 月费 | 包含 | 目标 |
|------|------|------|------|
| Free | ¥0 | 基础功能，限制次数 | 获客 + 收集反馈 |
| Pro | ¥29-99 | 高级功能，更多配额 | 核心收入 |
| Team/Business | ¥199-999 | 团队协作，优先支持 | B 端收入 |

## 日常 AI 产品的获客渠道

| 渠道 | 适合 | 成本 |
|------|------|------|
| 小红书 | 生活类/家庭类 | 内容成本 |
| 知乎 | 知识类/效率类 | 内容成本 |
| 抖音/B 站 | 场景化演示 | 视频制作 |
| V2EX/少数派 | 效率工具/技术类 | 零成本 |
| 微信朋友圈/群 | 种子用户 | 零成本 |
| Product Hunt | 出海方向 | 零成本 |
| App Store 优化 | 移动应用 | ASO 优化 |

## 关键指标（产品化阶段）

| 指标 | 含义 | 健康值 |
|------|------|--------|
| **MAU** | 月活跃用户 | 持续增长 |
| **Retention D30** | 30 天留存率 | > 25% |
| **Churn Rate** | 月流失率 | < 5% |
| **LTV / CAC** | 用户终身价值 / 获客成本 | > 3 |
| **NPS** | 净推荐值 | > 40 |
| **MRR** | 月经常性收入 | 持续增长 |

## 迭代节奏

```
每周：看数据 → 听用户反馈 → 修 bug → 小优化
每月：功能迭代 → 增长实验 → 竞品追踪
每季度：战略回顾 → 大版本规划 → 专利续展
```
