# 痛点发现与筛选

## 痛点是什么

> 痛点 = 用户在做某件事时反复遇到的**不便、低效或负面体验**，且现有方案无法很好解决。

好的痛点具有特征：**高频、刚需、有情绪、愿意付费**。

## 痛点发现渠道

### 1. 自身观察（最直接）

| 场景 | 自问 |
|------|------|
| 日常生活 | 今天我因为什么感到烦躁/浪费时间？ |
| 反复操作 | 有没有一件事我每周/每天都要手动重复做？ |
| 工具缺失 | 有没有我想做但因为没有工具而放弃的事？ |
| 多步操作 | 有没有一个流程需要切换 3 个以上工具/平台？ |

### 2. 社区扫描（规模验证）

| 平台 | 搜索关键词 | 关注点 |
|------|-----------|--------|
| 小红书 | "求推荐"、"有没有XX工具"、"受不了XX" | 消费决策痛点 |
| 知乎 | "为什么没有"、"怎么解决XX"、"XX的痛点" | 深层需求讨论 |
| Reddit | "I wish there was"、"Is there a tool for" | 国际视角 |
| V2EX | "有没有实现XX的方案" | 技术人群需求 |
| 豆瓣 | 生活类小组讨论 | 生活方式痛点 |
| 淘宝评价 | 差评、追评 | 现有产品的不足 |

### 3. 趋势洞察

- **Google Trends** — 搜索量上升的新需求
- **Product Hunt** — 最近热门的新工具，满足的什么需求？
- **App Store 评论** — 同类 App 的差评在抱怨什么？
- **天眼查/企查查** — 最近融资的创业公司在做什么？

## 痛点筛选清单

发现一个痛点后，用以下清单快速筛选：

- [ ] 这个痛点我自己遇到过吗？（优先自己懂的）
- [ ] 至少多少人会遇到？（TAM 够大吗）
- [ ] 现在用户怎么解决？（替代方案是什么）
- [ ] 现有方案的缺点是什么？（为什么还不够好）
- [ ] 这个痛点是"止痛药"还是"维生素"？（刚需 vs 改善）
- [ ] AI + 自动化能带来 10 倍改善吗？
- [ ] 解决方案可以申请专利吗？

## 痛点分级

| 等级 | 描述 | 举例 |
|------|------|------|
| 🔴 P0 — 断腿痛点 | 用户必须解决，否则生活/工作严重受影响 | 报税软件（必须报税） |
| 🟠 P1 — 高频摩擦 | 每天都遇到，虽不致命但很烦 | 多平台消息管理 |
| 🟡 P2 — 低频但痛苦 | 不常发生，但发生时很难受 | 搬家、装修 |
| 🟢 P3 — 锦上添花 | 有更好，没有也能过 | 照片自动整理 |

**优先 P0 和 P1。P2 需要看市场规模。P3 通常不是好创业方向。**
