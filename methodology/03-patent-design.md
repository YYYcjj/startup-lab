# 发明专利设计方法

## 专利的本质

> 专利 = 用**公开**换取**独占**。你告诉世界你的技术方案，换取 20 年的独占权。

对于创业公司，专利的价值：
- **防御**：防止大公司抄袭后把你挤出市场
- **资产**：融资/并购时的谈判筹码
- **壁垒**：延迟竞争对手进入的时间

## 什么可以申请发明专利

中国《专利法》第二条：发明是指对**产品、方法或者其改进**所提出的新的技术方案。

| 可申请 | 不可申请 |
|--------|----------|
| 新的算法/模型架构 | 纯数学方法 |
| 自动化流程 + 技术方案 | 纯商业规则 |
| AI + 硬件的结合方案 | 自然规律发现 |
| 数据处理的新方法 | 计算机程序本身（需要+技术效果） |

### AI + 自动化方向的专利机会

| 方向 | 专利切入点举例 |
|------|---------------|
| 自然语言处理 | 特定场景的意图理解方法、多轮对话状态追踪 |
| 个性化推荐 | 基于行为数据的混合推荐算法 |
| 自动化决策 | 多因素优化决策引擎 |
| 跨平台集成 | 异构系统数据同步与编排方法 |
| 图像识别 | 特定场景的视觉特征提取方法 |
| 预测分析 | 基于多源数据的预测模型训练方法 |

## 专利设计三步法

### Step 1：技术拆解

把解决方案拆成技术组件：

```
用户需求 → 功能模块 A → 技术方案 1
         → 功能模块 B → 技术方案 2
         → 功能模块 C → 技术方案 3
```

### Step 2：找创新点

每个技术方案问三个问题：
- 和现有方案相比，哪里不同？（不同点）
- 这个不同带来了什么好处？（技术效果）
- 这个不同是不是显而易见的？（创造性）

### Step 3：构建权利要求

```
一种 [产品/方法]，其特征在于，包括：
  步骤A：[具体技术手段]，用于实现[功能/效果]；
  步骤B：[具体技术手段]，用于实现[功能/效果]；
  其中，[创新点描述]。
```

## 专利撰写核心原则

### 1. 技术问题 → 技术手段 → 技术效果

> ❌ "本发明解决了用户记账麻烦的问题"
>
> ✅ "本发明提供一种基于 OCR 识别和 NLP 语义分类的自动记账方法，通过...实现...达到了...的技术效果"

### 2. 从宽到窄写权利要求

```
权利要求 1（独立权利要求，最宽）：
  一种自动分类方法，其特征在于...

权利要求 2-5（从属权利要求，逐步收窄）：
  如权利要求 1 所述的方法，其中步骤 A 具体为...
```

### 3. 有图有真相

- 系统架构图
- 方法流程图
- 数据结构示意图
- 用户界面示意图

## 专利申请前必做

- [ ] **专利检索**：在 [中国专利公布公告](http://epub.sipo.gov.cn) 和 [Google Patents](https://patents.google.com) 检索确认无重复
- [ ] **保密审查**：申请前不要公开发表、不要开源、不要在社交媒体讨论技术细节
- [ ] **时间戳**：保留所有研发记录（实验数据、会议纪要、邮件），证明"发明日"
- [ ] **发明人确认**：确认所有对发明有实质性贡献的人
