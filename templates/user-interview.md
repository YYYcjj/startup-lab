# 用户访谈提纲

> 目标：验证痛点是否真实、了解用户真实行为、测试方案可行性。
> 每次访谈 20-30 分钟，记录关键信息。

---

## 访谈准备

| 项目 | 内容 |
|------|------|
| **访谈编号** | U-00X |
| **日期** | |
| **访谈对象** | （姓名/昵称，可用代号） |
| **用户画像** | （年龄、职业、与痛点相关的背景） |
| **访谈方式** | 面对面 / 电话 / 视频 / 微信 |
| **假设待验证** | （此次访谈要验证什么假设？） |

---

## 开场（2 分钟）

> "你好，我正在做一个关于 [话题] 的研究，想了解你的真实体验。没有标准答案，你怎么想的就怎么说。"

---

## 背景了解（5 分钟）

1. 你平时 [相关场景] 大概多久一次？
2. 你是怎么做的？能描述一下完整过程吗？
3. 这个过程里最让你烦的是哪个环节？
4. 你有尝试过用什么工具/方法来改善吗？

---

## 痛点深挖（10 分钟）

5. **上次遇到这个问题是什么时候？** 能详细说说当时的情况吗？
6. 当时你做了什么？花了多长时间？
7. 你觉得如果当时有一个工具能帮你 ____，你会用吗？
8. **如果这个问题被完美解决了，你的生活/工作会有什么变化？**

---

## 方案测试（8 分钟）

> ⚠️ 不要问"你觉得这个想法怎么样"，而是展示具体方案

9. 如果有一个工具能 [核心功能]，你第一个想让它帮你做什么？
10. 你愿意为这样的工具付费吗？大概多少范围？
    - [ ] 免费才用
    - [ ] ¥9-29 / 月
    - [ ] ¥30-99 / 月
    - [ ] ¥100+ / 月
11. 有没有什么功能是你觉得"没有就不想用"的？
12. 你会把这个工具推荐给谁？

---

## 收尾（3 分钟）

13. 还有什么我没问到但你觉得重要的吗？
14. 可以帮我介绍 1-2 个可能有同样需求的朋友吗？

---

## 访谈后总结

| 项目 | 内容 |
|------|------|
| **痛点确认** | （痛点真实吗？程度如何？） |
| **新发现** | （有没有意料之外的信息？） |
| **方案反馈** | （对方案的态度：积极/中立/消极） |
| **付费信号** | （有没有明确付费意愿？） |
| **下一步** | |

---

## 信号判断

| 🟢 强信号 | 🟡 弱信号 | 🔴 否定信号 |
|------------|------------|-------------|
| 主动说"我需要这个" | "还不错" | "好像没什么用" |
| 追问什么时候能用 | 要思考很久 | "XX 工具也能做啊" |
| 主动提付费价格 | "免费的话会试试" | 直接拒绝付费 |
| 愿意介绍朋友 | 不主动推荐 | 不理解为什么要用 |
| 清楚描述痛点细节 | 描述模糊 | 说"我没什么痛点" |
