# Startup Lab 🧪

> **日常 × AI × 自动化** — 从用户痛点出发，设计发明专利，打造可落地的产品。

## 核心理念

大多数伟大的产品，不是从技术出发，而是从**一个被忽视的日常痛点**开始。

这个实验室的目标是建立一套系统化的方法论：**发现痛点 → 验证需求 → 设计专利 → 原型验证 → 产品化**。聚焦 AI + 自动化技术，解决普通人在日常生活中遇到的真实问题。

## 为什么是「日常 × AI × 自动化」

| 维度 | 分析 |
|------|------|
| **日常需求** | 高频、刚需、用户基数大、痛点真实且可验证 |
| **AI 能力** | LLM 理解自然语言、图像识别、预测分析，能处理模糊的日常场景 |
| **自动化** | 降低用户操作成本，把"麻烦事"变成"自动完成" |
| **交叉优势** | AI + 自动化的组合在专利申请上有较大创新空间 |

## 快速开始

1. 阅读 [`methodology/00-overview.md`](methodology/00-overview.md) 了解完整框架
2. 从日常生活或 [`research/`](research/) 中找到感兴趣的方向
3. 用 [`templates/pain-point-canvas.md`](templates/pain-point-canvas.md) 记录痛点
4. 用 [`templates/lean-canvas.md`](templates/lean-canvas.md) 验证商业可行性
5. 如涉及技术创新，用 [`templates/patent-brief.md`](templates/patent-brief.md) 准备专利交底书
