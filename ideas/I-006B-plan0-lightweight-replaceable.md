# D3O 防护秋裤 — 轻量化可替换方案

> **目标**：做一条老人愿意天天穿的秋裤，防护效果在，但穿起来完全没感觉。

---

## 一、核心矛盾

```
防护不是问题   材料不是问题   成本也不是问题
    │               │               │
    └───────────────┬───────────────┘
                    ↓
          唯一问题：老人愿不愿意穿？
                    │
           ┌────────┴────────┐
           ↓                  ↓
       太重/太厚           不穿了
       太闷/太热    →     等于零防护
       太像护具
```

**所以"怎么做"的答案不是追求"吸能率最高"，而是追求"怎么做到让老人穿了还想穿"。**

## 二、轻量化方案

### 2.1 总重量目标

| 对比项 | 重量 | 备注 |
|--------|------|------|
| 普通德绒秋裤（L 码） | ~180g | 老人的日常参照物 |
| EVA 护臀裤 | ~350-500g | 太沉了，所以不愿穿 |
| **我们的 D3O 防护秋裤** | **≤ 230g** | 只比普通秋裤重 50g |
| 其中防护垫片总重 | ~50g | 双侧髋部各 20g + 尾椎 10g |

> 目标：穿上几乎感觉不到和普通秋裤的区别。

### 2.2 轻量化怎么做

#### (1) 材料减重：蜂窝镂空

| 方案 | 重量 | 减重比例 | 防护影响 |
|------|------|----------|----------|
| 实心 D3O 片 | ~72g | 基准 | 最强但最重 |
| 六边形蜂窝 30%镂空 | ~50g | -30% | 防护略有下降（约90%→85%），但透气+减重 |
| 六边形蜂窝 40%镂空 | ~43g | -40% | 防护下降较明显 |
| 打孔阵列 15%镂空 | ~61g | -15% | 防护几乎不变，但透气提升有限 |

**推荐：六边形蜂窝 30% 镂空。** 减重 30% 的同时透气性提升 50%，防护仅降低 5%。

#### (2) 精准定位：只保护三个点

不是整条裤子都做防护，只在最需要的地方加垫片：
- 双侧髋部（12cm × 10cm，覆盖股骨大转子）
- 尾椎（8cm × 6cm）
- 总面积 ~312cm²，不足整条秋裤面积的 15%

#### (3) 厚度控制：6-8mm 黄金厚度

| 厚度 | 防护效果 | 穿着体验 | 适用场景 |
|------|----------|----------|----------|
| 12mm | 极好（≥95%） | 太厚，硌 | ❌ 不可接受 |
| 10mm | 很好（92%） | 较厚 | ⚠️ 可接受 |
| **8mm** | **好（~88%）** | **穿上活动不硌** | **👍 秋冬款推荐** |
| **6mm** | **较好（~80%）** | **几乎感觉不到** | **👍 夏季款推荐** |
| 4mm | 一般（~65%） | 完全无感 | 不够保险 |

## 三、可替换化方案

### 3.1 固定方式对比

| 方案 | 优点 | 缺点 | 推荐 |
|------|------|------|:----:|
| **魔术贴** | 成本低、固定稳、拆卸方便 | 多次机洗后粘性下降 | ⭐⭐⭐ |
| **磁吸扣** | 无感、拆卸最快 | 磁铁可能位移、成本较高 | ⭐⭐⭐⭐ |
| **拉链袋** | 垫片不接触皮肤 | 拉链硌人、拉链坏了就废 | ⭐⭐ |
| **硅胶防滑点** | 无感、简单 | 洗几次就掉 | ⭐ |
| **子母扣** | 最稳、耐用 | 老人不好操作 | ⭐⭐ |

**推荐方案：磁吸扣**

**磁铁规格**：
- 垫片侧：N52 钕磁铁，直径 10mm × 厚度 3mm，每颗 1.8g
- 秋裤侧：N52 钕磁铁，直径 8mm × 厚度 2mm，每颗 0.8g
- 总重（含双侧髋+尾椎）：~10g
- 吸力：每对 ~200g 拉力，不会位移

### 3.2 使用流程

```
用户视角：
  1. 收到秋裤 → 垫片已装好 → 直接穿
  2. 要洗秋裤 → 用手拿出垫片
     → 垫片用湿布擦，不进��洗
     → 秋裤扔洗衣机正常洗
  3. 晾干后 → 垫片按磁铁位置贴回去 → 继续穿
  4. 垫片寿命到了（约 2-3 年）→ 购买替换垫片 ¥29-49/对

换季：秋冬穿德绒款 → 春夏换莫代尔款，垫片通用
```

### 3.3 替换成本

| 替换件 | 价格 | 更换周期 |
|--------|------|----------|
| 髋部+尾椎垫片一对 | ¥39-49 | 2-3 年（D3O 寿命） |
| 秋裤本体 | ¥69-129 | 1-2 年（正常服装寿命） |

## 六、验证步骤

### Phase 0：手工样裤（¥500，1 周）

```
1. 淘宝买 D3O 片材 ¥100
2. 买一条德绒秋裤 ¥60
3. 美工刀切割 D3O 为髋部形状
4. 手工缝魔术贴固定
5. 自己穿上感受：坐下/走路/弯腰/深蹲
6. 调整：太厚→削薄，硌人→改形状
```

### Phase 1：小范围试穿（¥2,000，2 周）

```
找 10 位 65+ 老人试穿 3 天。
核心问题只有两个：
  1. 愿意每天穿吗？（≥ 8/10 → 过关）
  2. 觉得有用吗？（≥ 7/10 → 过关）
```

## 七、一句话总结

> 不做"最硬核的护具"——做"一条看不出是护具的秋裤"。
> 
> 轻量：全靠蜂窝镂空 + 精准定位三个点 + D3O 本身薄的特性
> 可替换：磁吸固定，垫片可拆卸，秋裤正常机洗
> 
> 核心假设验证仅需 ¥500 和 1 周时间。
