# 方案二：隐形可穿戴防护

> **核心洞察**：老人不是不穿护具——是不穿「看起来像护具」的东西。把保护藏在他们本来就在穿的衣服里。

---

## 一、产品概念

**不是「防摔马甲」，而是「有防摔功能的正常衣服」。**

- 外观 = 一件普通羽绒马甲 / 棉背心 / 轻薄外套
- 夹层里藏着 3mm 厚的折叠气囊 + 微型传感器
- 老人自己可能都不知道里面有保护功能
- 检测跌倒 → 0.08 秒气囊充满 → 髋部/尾椎/肋骨被包住 → 摔下去像摔在瑜伽球上

---

## 二、技术方案

### 2.1 超薄折叠气囊（核心壁垒）

这是整个方案的灵魂。现有气囊的问题：

| 现有产品 | 气囊厚度 | 充气后体积 | 问题 |
|----------|----------|-----------|------|
| Helite Hip Air | ~12mm | 大 | 腰带鼓一圈，夏天没法穿 |
| 衣带保 | ~15mm | 很大 | 像穿了防弹衣 |
| 汽车气囊 | ~50mm | 巨大 | 根本不适用于穿戴 |

**我们需要**：折叠态 < 3mm，充气态足以吸收跌倒冲击。

```
材料方案对比：

方案 A：TPU 覆膜尼龙折叠气囊
  - 折叠态厚度：2.5mm
  - 充气态厚度：60-80mm（双层叠加）
  - 折叠方式：Z 字折叠 + 魔术贴定位
  - 优点：成熟工艺、成本低
  - 缺点：反复折叠可能产生折痕疲劳

方案 B：硅胶涂层面料 + 激光焊接
  - 折叠态厚度：2mm
  - 充气态厚度：50-70mm
  - 优点：无折痕、寿命长
  - 缺点：成本较高

方案 C（远期）：3D 编织一体化气囊
  - 类似 Nike Air 气垫技术
  - 折叠态 < 1.5mm
  - 无需折叠，自然扁平
  - 但需要定制产线
```

**推荐：方案 A 起步，验证后过渡到方案 B。**

### 2.2 微型充气系统

| 方案 | 原理 | 充气速度 | 可重复用 | 体积 |
|------|------|----------|----------|------|
| **压缩 CO₂ 气瓶** | 刺破释放 | 0.03-0.05s | ❌ 一次性 | 钢笔大小 |
| **微型火药驱动** | 叠氮化钠产气 | 0.02-0.04s | ❌ 一次性 | 最小 |
| **压缩空气+电磁阀** | 高压储气罐 | 0.05-0.08s | ✅ 可充气 | 充电宝大小 |
| **微型涡轮泵** | 高速电机泵 | 0.2-0.3s | ✅ 可充电 | 手机大小 |

**推荐：压缩 CO₂ 气瓶方案**。

- 尺寸：直径 18mm × 长 60mm（约一支签字笔）
- 重量：~30g
- 成本：¥8-15/个
- 更换：跌倒触发后更换（类似打印机墨盒，拧下来换新的）
- 一对气瓶保护双侧髋部，一个气瓶保护尾椎

```
衣物内布局示意（羽绒马甲为例）：

          正面                背面
    ┌──────────────┐    ┌──────────────┐
    │              │    │              │
    │   [传感器]    │    │  [传感器]    │

    │              │    │              │

### 2.3 传感器与算法

| 传感器 | 作用 | 型号参考 |
|--------|------|----------|
| 6 轴 IMU | 检测加速度突变+角速度变化 | ICM-42688-P（<¥20） |
| 气压计 | 辅助判断高度突变 | BMP390（<¥10） |
| 毫米波接近传感器 | 检测地面接近速度 | 定制 |

**算法逻辑（不是简单阈值，是跌倒意图判断）**：

```
数据采集（100Hz）
  │
  ├─ 正常过滤层
  │   ├─ 坐下/蹲下：加速度渐进，角速度小 → 忽略
  │   ├─ 弯腰捡东西：垂直加速度为主 → 忽略
  │   └─ 躺下睡觉：水平位移为主 → 忽略
  │
  ├─ 预警层
  │   ├─ 身体倾斜角度 > 45° + 持续增大
  │   └─ 横向加速度突变 + 失去支撑信号
  │
  └─ 触发层 → 跌倒确认条件：
      ✅ 加速度峰值 > 2.5g
      ✅ 角速度变化 > 200°/s
      ✅ 高度快速下降（气压计）
      ✅ 冲击前姿态 = 非正常姿势
      → 0.05s 内确认 → 触发气囊
```

**降低误报的关键**：
- 不是单一阈值，而是多信号交叉验证
- 加入「老人行为模型」：老人日常动作模式学习，偏离基线才报警
- 三级判断：先预警（准备充气）→ 确认（触发）→ 误报取消（3s 内自动放气）

## 六、专利布局

| 序号 | 类型 | 名称 | 保护点 |
|------|------|------|--------|
| **P1** | 🔥 发明 | 一种可嵌入日常服装的超薄折叠式跌倒防护气囊系统 | 整个系统的核心——气囊折叠方式+嵌入衣物结构 |
| **P2** | 发明 | 基于多传感器交叉验证的跌倒意图预测及气囊触发方法 | 算法层——不是检测摔倒，是预测+验证后才触发 |
| **P3** | 实用新型 | 一种可拆卸模块化老人防摔衣物内胆 | 把电子模块+气囊做成可拆卸内胆，适配不同外套 |
| **P4** | 发明 | 一种日常穿戴式被动+主动混合跌倒防护方法 | 被动材料+D3O 常驻防护 + 主动气囊叠加触发 |
| **P5** | 外观 | 隐藏式防摔功能的多款服装外观设计 | 多款衣服的外观保护 |
| **P6** | 发明 | 三级级联判断的跌倒检测与防护触发方法 | 预警→确认→触发→误报取消的四阶段逻辑 |

**P1 是最关键的壁垒专利。** 如果能把「气囊折叠到 < 3mm 并嵌入正常服装」这个方案保护住，竞品要么做不出来，要么绕不过去。

**P1 权利要求的核心写法**：

```
一种可嵌入日常服装的跌倒防护系统，其特征在于，包括：

a) 至少一个折叠式气囊，所述气囊在未充气状态下以 Z 字形折叠，
   折叠后的总厚度不超过 3mm，且被布置于服装的内层和外层之间；
   
b) 充气装置，包括可更换的压缩气体瓶和电磁触发阀，
   所述气体瓶的容积不超过 20ml，触发后 0.08s 内完成气囊充气；

c) 传感器模块，包括六轴惯性测量单元和气压计，
   以不低于 100Hz 的频率采集运动数据；

d) 微控制器，执行多级跌倒判断算法，
   在确认跌倒事件后触发电磁阀释放气体。
```

```
