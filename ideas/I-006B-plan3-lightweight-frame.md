# 方案三：轻量化包围框架

> **核心洞察**：婴儿学步车的逻辑完全正确——周围一圈保护，怎么歪都不倒地。问题是现有老人版做得太丑、太笨、太像刑具。

---

## 一、产品概念

**一个轻到可以单手提起的环形框架，围在老人腰间高度，无论往哪个方向倾斜都会被框架接住。走累了随时变成椅子坐下。折叠后放进后备箱。**

它不是「助行器」，它是「随身安全气泡」。

---

## 二、机械结构设计

### 2.1 整体形态

```
             俯视图                          侧视图
    
       ┌─────────────────┐           老人
       │   ╭─────────╮   │           ┃
       │   │         │   │      ┌────╋────┐
       │   │  老人   │   │      │    ┃    │ ← 腰部护圈
       │   │  站位   │   │      │  ══╪══  │ ← 扶手环
       │   │         │   │      │    ┃    │
       ���   ╰───┬─┬───╯   │      │  ══╪══  │ ← 膝部感应圈
       │       │ │       │      │    ┃    │
       └───────┼─┼───────┘      └────╋────┘
               │ │                   ┃
            前方开口             4 个全向轮
          （可进出，不封闭）      
```

**关键设计语言**：
- 不是医疗白/灰 → 哑光深空灰/暖沙金/森林绿
- 不是方形钢管 → 椭圆形截面，无焊缝外观
- 不是功能外露 → 所有机械结构隐藏在外壳内
- 整体感觉 ≈ 高端行李箱/婴儿推车，而不是轮椅

### 2.2 三层防护圈

| 圈层 | 位置 | 功能 | 平时状态 |
|------|------|------|----------|
| **外圈（防护圈）** | 腰-髋高度，直径 85cm | 身体倾斜时接住，防止倒地 | 固定，环绕老人 |
| **中圈（扶手圈）** | 肘部高度 | 双手扶持、支撑身体 | 固定 |
| **内圈（感应圈）** | 膝部高度 | 检测老人步态、腿部分离趋势 | 固定，内置传感器 |

三层之间由 4 根竖杆连接，前方留 60cm 开口（老人正常进出不受阻）。

### 2.3 材料方案

| 部位 | 材料 | 理由 |
|------|------|------|
| 框架骨架 | 6061/7075 铝合金管 | 轻、强度够、不锈 |
| 框架外壳 | PC/ABS 一体成型 | 美观、耐撞、可配色 |
| 扶手包覆 | PU 自结皮（类似高端汽车方向盘） | 柔软防滑、冬暖夏凉 |
| 膝部感应圈 | 铝合金+TPE 包胶 | 碰撞不疼 |
| 轮子 | 麦克纳姆轮（4×4英寸） | 全向移动、原地旋转、过门槛 |
| 折叠铰链 | 不锈钢+自锁机构 | 承重、反复折叠不变形 |
| 轴承 | 陶瓷混合轴承 | 静音、免维护 |

### 2.4 重量与尺寸

| 参数 | 目标值 | 对比（现有产品） |
|------|--------|-----------------|
| 总重 | < 5.5kg | 雅德学步车 ~12kg |
| 外径 | 85cm | — |
| 内径（站立空间） | 65cm | — |
| 折叠后宽度 | < 25cm | 现有不能折叠或半折 |
| 折叠后高度 | < 90cm | — |
| 折叠后厚度 | < 30cm | — |
| 通过门宽 | 60cm（展开态，侧身通过） | 现有大多 > 70cm |
| 承重上限 | 120kg | — |
| 提到车上 | 单手可提（5.5kg ≈ 一桶 5L 水） | 现有搬不动 |

## 三、智能功能

### 3.1 主动平衡辅助（不是被动等人扶）

```
正常行走模式：
  全向轮自由滚动，零阻力
  老人走多快轮子跟多快

失衡检测（膝部感应圈检测到老人腿部偏移 > 预期）：
  Step 1: 偏移侧轮子瞬间锁止（电磁刹车，< 0.1s）
  Step 2: 框架形成刚性支撑点
  Step 3: 老人身体压向防护圈 → 被接住 → 不会倒地
  Step 4: 判断老人恢复站立 → 自动解锁，恢复正常行走

完全倒地（老人已坐地/躺地）：
  框架不倒，提供扶手让老人自己撑着爬起来
  不依赖他人帮助
```

### 3.2 传感器系统

| 传感器 | 位置 | 功能 |
|--------|------|------|
| 6 轴 IMU ×3 | 底部三角分布 | 检测框架自身是否倾斜/翻倒 |
| 压力传感器 ×8 | 防护圈内侧 | 检测老人身体是否压向防护圈 |
| 红外距离传感器 ×6 | 膝部感应圈 | 检测老人腿部位置、步态变化 |
| 激光 ToF ×2 | 前方 | 检测前方障碍物、台阶 |
| 轮速编码器 ×4 | 每个轮子 | 检测移动速度和方向 |

### 3.3 智能模式切换

| 模式 | 触发条件 | 行为 |
|------|----------|------|
| **自由行走** | 默认 | 全向轮自由、零阻力 |
| **辅助支撑** | 老人主动按压扶手 > 3s | 轮子增加阻尼（像推购物车的感觉） |
| **警觉模式** | 步态不稳检测 | 轮子半锁，随时准备全锁 |
| **锁定模式** | 失衡检测 / 老人坐下 | 全轮锁止 + 蜂鸣提醒家属 |
| **椅子模式** | 手动触发折叠 | 框架后半部折叠，变成带扶手的椅子 |
| **收纳模式** | 一键折叠 | 轮子内收，框架折叠成平板 |

## 四、折叠机构（核心专利点）

这是区别于市面上所有产品的关键。

```
展开态：                   折叠态：
┌────────────┐            ┌──┐
│ ╭──────╮  │            │  │ ← 25cm 宽
│ │      │  │            │  │
│ │  ○   │  │   →→→     │  │
│ │      │  │            │  │
│ ╰──────╯  │            │  │
└────────────┘            └──┘
  85cm 直径                 可立放/可平放
```

**折叠步骤（3 秒完成）**：

```
1. 踩下脚踏锁扣
2. 双手内推两侧扶手
3. 4 个全向轮自动内收
4. 前后两个半圆框架叠合
5. 自动锁止 → 可以拖着走（像行李箱）
```

**折叠机构设计**：
- 中央 4 连杆交叉铰链（类似折叠婴儿车的骨架）
- 每根连杆两端各有自锁关节
- 折叠时 4 个轮子向中心收缩
- 展开时有清晰的「咔嗒」锁定声

**专利点**：
- 一种四连杆交叉折叠的环形助行框架结构
- 联动轮组收放机构（折叠时轮子自动内收）

## 五、椅子模式

这是让老人「愿意用」而不是「被迫用」的关键功能。

老人心理：拿着助行器 = 我老了。但如果这东西能当椅子坐，出门散步累了随时坐下 = 这是个「聪明装备」。

```
椅子模式切换：

展开态（助行）              椅子模式
┌────────────┐            ┌────────────┐
│ ╭──────╮  │            │ ╭─        │
│ │      │  │            │ │  坐垫    │ ← 后半圈翻转成座面
│ │      │  │   →→→     │ │         │
│ │      │  │            │ │  扶手    │ ← 前半圈保留为扶手
│ ╰──────╯  │            │ ╰────────  │
│   4轮     │            │  4轮锁止   │
└────────────┘            └────────────┘
```

| 参数 | 规格 |
|------|------|
| 座面高度 | 50cm（适合中国老人平均身高） |
| 座面宽度 | 40cm |
| 承重 | 120kg |
| 切换时间 | < 1s（翻转即坐） |
| 恢复行走 | < 1s（站起来，座面自动弹回） |

## 六、关键场景

### 场景 1：在家日常
```
早上起床 → 从床边拉过框架（折叠状态展开）
          → 扶着站起来（辅助支撑模式）
          → 走去卫生间（自由行走模式）
          → 框架停在外面，老人进去（60cm 开口可进出）
          → 出来，继续走
          → 厨房做饭 → 切换椅子模式坐着择菜
          → 晚上回到床边 → 折叠收纳
```

### 场景 2：出门散步
```
折叠态 → 拖到车后备箱 → 到达公园 → 展开 → 散步
→ 累了 → 椅子模式坐下休息
→ 继续走 → 碰到台阶 → 智能检测坡度，自动增加轮子阻尼
→ 回家 → 折叠 → 放回后备箱
```

### 场景 3：摔倒自救
```
老人走路失去平衡
  → 身体倒向右侧
  → 红外传感器检测到腿部异常位移
  → 右侧轮子瞬间锁止（< 0.1s）
  → 老人身体压在防护圈上，被接住，臀部落座
  → 框架不倒（底部配重+宽轮距）
  → 老人稳住后扶着扶手自己站起来
  → 全程不需要他人帮助
```

## 十、为什么老人会愿意用

这是整个方案最核心的问题。

```
现有助行器的问题回路：

  "这是助行器" → "我老了/病了/残了才用" → "我不要"
  
我们的破解回路：

  "这是什么东西？" 
  → "像个出行装备，挺酷的"
  → "走累了还能坐着"
  → "收起来这么小？放后备箱很方便"
  → "那我试试"
  
关键：产品定义不是"助行器"，而是"个人出行伴侣"。
营销语言：不叫「老人学步车」，叫「漫步环」/「随身座驾」/「银发出行伴侣」。
```

**设计细节强化「不像助行器」**：
- 没有红十字标志
- 没有"老年用品"配色（米色/棕色/灰白）
- 配色参考：Apple 深空灰、Dyson 镍色、Rimowa 铝本色
- 包装盒像消费电子产品，不像医疗器械
- 说明书用「设置」不用「使用须知」，用「旅程」不用「康复」

## 十一、风险评估

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| 重量做不到 < 5.5kg | 中 | 高 | 换碳纤维（成本 +¥500，降重 30%） |
