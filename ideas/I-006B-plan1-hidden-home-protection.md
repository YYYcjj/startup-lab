# 方案一：家居化隐藏式防摔系统

> **核心洞察**：最好的防护是看不出来的防护。不让老人"穿"什么，让家本身变成保护网。

---

## 一、产品概念

**不是卖一个设备，而是卖一套「看不见的防摔网」——嵌入在日常家具和装修里，平时毫无存在感，需要时自动出现。**

老人不需要改变任何习惯，不需要穿戴任何东西。防摔是家的一部分，像烟雾报警器一样隐形存在。

## 三、核心模块详设

### 模块 1：隐藏式智能扶手

**现状**：传统扶手装在墙上，等于告诉所有人"这个家里有老人/病人"。

**方案**：平时看起来是普通装饰面板/护墙板，受压或检测到老人靠近时自动弹出。

```
┌──────────────────────────────┐
│  正常状态                    │
│  ┌─────────────────────────┐ │
│  │ 木纹装饰面板（与墙面一致）  │ │
│  │                         │ │
│  │   看起来就是一面墙         │ │
│  └─────────────────────────┘ │
│                              │
│  触发状态（0.3s弹出）         │
│  ┌─────────────────────────┐ │
│  │ ██  扶手弹出  ██         │ │
│  │    ════════════         │ │
│  │    ██         ██         │ │
│  └─────────────────────────┘ │
└──────────────────────────────┘
```

| 参数 | 规格 |
|------|------|
| 弹出速度 | < 0.3s |
| 承重 | ≥ 150kg（静态）/ ≥ 80kg（动态拉扯） |
| 弹出距离 | 墙面外 8-12cm |
| 触发方式 | ①毫米波雷达检测老人靠近 ②轻压面板手动触发 ③跌倒事件自动触发 |
| 供电 | 内置电池（2 年续航）或接入 220V |
| 安装 | 膨胀螺丝固定，可覆盖在现有墙面上 |
| 外观 | 木纹/纯色/可定制，与装修风格融合 |

**触发逻辑**：
```
走廊雷达检测到老人夜间移动
  → 老人距离扶手面板 < 1m
  → 扶手预先半弹出（1cm，无声）
  → 老人手触碰或身体倾斜
  → 完全弹出锁定
  → 老人离开 30s 后自动收回
```

**专利点**：
- 一种基于雷达预判的隐藏式自动弹出扶手
- 扶手的弹出机构：弹簧预紧+电磁锁释放（不被断电影响，断电=自动弹出）
- 压力感应面板：平时是装饰面，受压触发

### 模块 2：智能夜灯导航系统

**场景**：老人晚上起夜，摸黑走路是跌倒最高发场景。

**方案**：不是一盏夜灯，而是一条会「自动亮起来的路径」。

```
卧室 → 走廊 → 卫生间

正常状态：全部熄灭

老人起身（床垫传感器检测）：
  ┌──────┐     ┌──────┐     ┌──────┐
  │ 💡床下 │ →  │ 💡走廊 │ →  │ 💡卫生间│
  └──────┘     └──────┘     └──────┘
  柔光3000K   依次点亮      到达后全部亮
  
老人返回床上后：
  30s 延迟 → 依次熄灭
```

| 参数 | 规格 |
|------|------|
| 色温 | 3000K 暖黄（不刺眼、不影响褪黑素） |
| 亮度 | 5-15 流明（足够看清地面，不晃眼） |
| 安装 | 踢脚线嵌入式 / 地脚灯 / 插座直插式 |
| 通信 | Zigbee / BLE Mesh，无需 WiFi |
| 供电 | 插座取电或纽扣电池（1 年） |
| 联动 | 老人跌倒 → 所有灯全亮 + 红色闪烁 |

**特殊设计**：
- 灯光是「从地面往上打」而不是天花板往下照——不会晃到眼睛
- 渐变亮起（1.5s 淡入），不是突然亮——避免惊吓
- 如果老人超过 15 分钟没返回，灯光开始脉冲闪烁提醒家属

**专利点**：
- 基于老人行为预测的分布式夜灯导航方法
- 灯光路径的渐进式梯度照明策略（远离老人处暗，靠近老人处亮）


### 模块 3：智能床沿辅助系统

**场景**：老人从躺着到坐起来再到站起来，是最容易失衡的三个动作。

**方案**：床垫或床架内置姿态感知 + 辅助支撑。

```
阶段 1：老人有起身意图（翻身频率增加）
  → 床沿 LED 微亮
  → 床头缓缓抬起 15°（帮助坐起来）

阶段 2：老人坐起
  → 床沿侧边扶手自动升出 15cm
  → 老人可以扶着站起来

阶段 3：老人站立
  → 扶手保持 5s 确认稳定
  → 自动收回
```

| 参数 | 规格 |
|------|------|
| 床垫传感器 | 压力薄膜阵列，检测睡姿/翻身/离床 |
| 辅助抬升 | 电动推杆，最大推力 150kg，速度可调 |
| 侧扶手 | 铝合金+软包，伸出高度 60cm（适合抓握） |
| 改造方式 | **不换床**：床垫式（铺在现有床垫下）或床架附加模块 |

**关键设计**：
- 床垫式方案：3cm 厚的感应垫铺在现有床垫下，不改变老人熟悉的床
- 扶手是可拆卸模块，夹在床架侧面，不需要打孔
- 所有电子元件在床垫下层，不发热、无辐射

**专利点**：
- 一种非侵入式（不改床体）的床沿辅助起身装置
- 基于压力分布变化的老人起身意图预测方法

### 模块 4：浴室防跌套件

**场景**：浴室是跌倒最高发区（湿滑+空间小+穿脱衣物）。

| 组件 | 功能 | 安装方式 |
|------|------|----------|
| **防滑地垫 2.0** | 比普通防滑垫多一层吸水速干层 + 底部吸盘 | 铺在原有地面上 |
| **马桶辅助臂** | 平时折叠在马桶侧面，按键弹出 | 免打孔夹在马桶上 |
| **淋浴折叠凳** | 壁挂式，不用时折叠贴墙 | 膨胀螺丝上墙 |
| **智能浴霸联动** | 检测老人进入→自动排风除湿→地面速干 | 替换原有浴霸 |

**专利点**：
- 一种折叠式马桶辅助起身装置
- 基于浴霸联动的浴室主动除湿防滑系统
