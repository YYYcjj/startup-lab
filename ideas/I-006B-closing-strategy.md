## 一、最终产品形态

### 核心产品：D3O 防护内裤/秋裤（必做 🔥）

| 维度 | 决策 |
|------|------|
| 技术路线 | D3O 被动材料（非牛顿流体剪切增稠），非电子气囊 |
| 防护部位 | 双侧髋部（8mm）+ 尾椎（6mm），仅此三点 |
| 轻量化 | 蜂窝镂空 30%，总重 ≤ 230g（仅比普通秋裤重 50g） |
| 可替换 | 磁吸扣固定垫片，垫片可拆，秋裤直接机洗 |
| 定价 | ¥119-169 |
| BOM | ¥54/条 |
| 首批投入 | ¥5 万（500 条） |
| 毛利率 | 68% |
| 为什么做这个？ | 老人**本来就要穿**秋裤/内裤，没有额外的穿戴决策 |

### 扩展产品：D3O 保暖防护马甲

| 维度 | 决策 |
|------|------|
| 逻辑 | 冬天冷→老人本来就会穿马甲→我们的马甲顺便有 D3O 背部防护 |
| 定价 | ¥159 |
| 说明 | 不是"买件护具"，是"买件保暖马甲，顺便背部有防护" |

### 不做：头部穿戴式防护

| 原因 | 说明 |
|------|------|
| 老人不喜欢戴帽子 | 额外穿戴=额外抗拒，穿戴率低 |
| D3O 不适合头部 | D3O 靠材料吸能，无法替代气囊的缓冲空间 |
| 替代方案 | 环境改造（防滑地垫+D3O 靠垫），不依赖老人每天操作 |

## 二、与竞品对比总表

| | 气囊马甲（衣带保/信安智囊） | 气囊帽子（多个国产品） | D3O 防护内裤+马甲（我们） |
|--|:---:|:---:|:---:|
| 覆盖部位 | 髋+背+胸 | 全头部 | **髋+尾椎+背部** |
| 总价 | ¥2,500-4,500 | ¥380 | **¥278-328** |
| 需要充电 | ✅ 3-7天一次 | ✅ 18天一次 | **❌ 从不** |
| 触发后 | 换气瓶¥100-200 | 换气瓶 | **继续穿** |
| 误报风险 | ✅ 存在 | ✅ 存在 | **❌ 不存在** |

| 有效保护率 | 90%×20%=18% | 78%×15%=12% | **85%×80%=68%** |

**核心逻辑**：
> 穿在身上的保护才是真保护。
> 保护效果 × 穿戴率 = 实际有效保护率
> 竞品走"技术强但没人穿"的路，我们走"技术够用但人人穿"的路。

## 三、战略定位

### 我们的领地
- **躯干+髋部日常防护**
- **穿戴率优先**—让防护变成"本来就要穿的衣服"，而不是"额外穿的护具"

### 不碰的领域
- 头部气囊帽类（交给竞品做）
- 电子传感器类（维护成本太高，老人不愿管）

### 与竞品的关系
**不是竞争，是互补。**
- 老人穿我们的防护内裤 + 戴竞品的气囊帽 = 全身防护
- 老人只穿我们的内裤 = 至少髋部保护了（总比什么都不穿强）
