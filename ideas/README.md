## 如何添加新创意

1. 复制 [`templates/pain-point-canvas.md`](../templates/pain-point-canvas.md)
2. 新文件命名为 `I-XXX-简短名称.md`，放在 `ideas/` 目录
3. 填写完整的痛点画布
4. 在本页添加条目
